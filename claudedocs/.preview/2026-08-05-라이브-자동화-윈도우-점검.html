# 문제 상태
1 Codex가 SSH 공개키 인증 거부로 중단 해결 — 키가 틀렸을 뿐. ~/.aimax-ops/aixlife_win_key 로 정상 접속
2 7/17~7/31 모든 실행이 discovering에서 즉사 해결 — 원인은 Windows OAuth 리프레시 토큰 invalid_grant
3 Windows 자격증명 3종이 죽은 상태 해결 — Mac의 유효한 메이크패밀리 토큰을 암호화 번들로 재이관 (DPAPI)
4 실패 원인이 로그에 안 남음 해결 — $ErrorActionPreference="Stop" + 2>&1 조합이 첫 stderr에서 파이프라인을 끊어 원인을 통째로 삼키고 있었음
5 로그 인코딩 깨짐(UTF-16 혼입) 해결 — 전 구간 UTF-8 통일
6 Windows 코드가 구버전일 가능성 문제 없음 — 핵심 파일 4개 해시가 Mac 최신본과 일치

검증: Windows에서 러너를 실제 실행 → OAuth·라운지 DB·영상 탐색 전 구간 통과, exit=0, 로그 정상 기록.

액션 1. Windows PC에서 전용 Edge 프로필에 YouTube 로그인 (필수, 약 2분)

자동화는 YouTube Studio에서 원본을 내려받기 위해 전용 Edge 프로필을 씁니다.
그 프로필의 구글 쿠키가 0개라 다운로드 단계에서 멈춥니다.

기존 설계는 "평소 쓰는 Edge의 쿠키를 전용 프로필로 복사"였는데, 지금은 이 방식이 원천적으로 불가능합니다.
Edge가 쿠키를 App-Bound 암호화로 잠가서 다른 프로필로 옮기면 복호화가 안 됩니다.
(yt-dlp 우회 경로도 같은 이유로 실패 — yt-dlp 이슈 #10927에서 확인)

즉 전용 프로필에서 직접 한 번 로그인하는 것 외에 방법이 없습니다.

Windows PC에서 아래를 실행하고, 열리는 창에서 메이크패밀리 채널 계정으로 로그인해 주세요.

"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --user-data-dir="C:\Users\likim\AppData\Local\AIMAX\LiveReplay\edge-profile" --profile-directory=Default https://studio.youtube.com

Studio 화면이 정상적으로 보이면 창을 닫으시면 됩니다. 나머지는 제가 검증합니다.

주의: 이 쿠키는 영구가 아닙니다. 만료되면 같은 로그인을 다시 해야 합니다.
이게 이 자동화의 구조적 약점입니다.

액션 2. Google Cloud Console에서 OAuth 앱을 Production으로 전환 (권장)

Testing 앱의 리프레시 토큰은 구글 정책상 7일 뒤 자동 만료됩니다.
이대로 두면 오늘 넣은 토큰도 다음 주에 또 죽습니다.

  • Google Cloud Console → 해당 프로젝트(dynamic-camp-491500-d6) → OAuth consent screen
  • Publishing status가 Testing이면 → PUBLISH APP → In production
  • youtube.upload은 sensitive scope라 "미인증 앱" 경고 화면은 남지만, 7일 만료는 사라집니다

확인만 해주셔도 됩니다 — 이미 Production이면 원인은 다른 것이고, 제가 다시 추적하겠습니다.
