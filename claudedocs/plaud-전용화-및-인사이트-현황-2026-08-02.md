# 1부. PLAUD 전용화

## 지금 있는 것

| 화면 버튼 | 서버 엔드포인트 | 민수 사용 |
|---|---|---|
| PLAUD로 보내기 | (plaud 라우트) | **유일하게 씀** |
| MP3 다운로드 | `/download` | 안 씀 |
| 영상 다운로드 (화질 선택) | `/download-video` | 안 씀 |
| 2~5분할 | `/download-split` | 안 씀 |

## 제거안

**지울 것**
- 서버: `/download`, `/download-video`, `/download-split`, `/file/:id/:part`
- 확장: MP3 다운로드 버튼, 화질 선택 + 영상 다운로드, 2~5분할 버튼

**남길 것**
- PLAUD로 보내기, 시작/끝 구간 입력, 진행률 표시, `/progress`, `/health`
- 회의끝(`plaud-meeting`) 라우트 — 별개 기능이라 그대로 둔다

**주의 — 지우면 안 되는 것**
`/download-split`의 ffmpeg 분할 로직은 지금 유일하게 검증된 분할 코드다. 엔드포인트는 없애되 **분할 헬퍼 함수는 남겨 5시간 초과 자동 분할에 재사용**한다. 그냥 통으로 지우면 1부 작업을 다시 짜야 한다.

**부수 효과**: 화면이 버튼 1개로 줄어 오작동 여지가 사라진다. `server.js`(현재 84KB)도 눈에 띄게 줄어든다.

# 2부. 옵시디언 인사이트 — 지금 실제로 벌어지는 일

## 흐름 (자동, 사람 개입 0)

```
PLAUD 전사 완료
  → insight-processor.sh 자동 실행 (headless claude, 읽기 전용)
  → insight-rules.md + situation-pack.md(민수 현재 상황) + 전사 읽음
  → 노트 생성 → creator-os-vault/insights/videos/YYYY-MM-DD-슬러그.md
  → 데일리 노트에 한 줄 링크 추가
```

노트 1장 구조: frontmatter(category/assets/confidence/source/status) · 전체 요약(민수 상황 렌즈) · 핵심 문장 3~5 · **지금 제안 1액션+1질문** · 대기 제안 2~3 · 실행 로그

## 그런데 — 꺼내 쓸 수 있는 상태는 아니다

> **정정 (2026-08-02)**: 이 표의 초판에 "category 67/67 전부 세계관"이라고 적었으나 틀렸다.
> `uniq`가 한글을 제대로 처리하지 못해 나온 집계 오류였다. awk로 다시 세면 **실행기법 51 / 세계관 7 /
> 수익화사례 6 / 콘텐츠전략 2 / 오퍼공식 1**로 5축 분류는 정상 작동 중이다. 아래는 재집계 결과다.

| 항목 | 실측 | 판정 |
|---|---|---|
| 분류(category) | 실행기법 51 · 세계관 7 · 수익화사례 6 · 콘텐츠전략 2 · 오퍼공식 1 | **정상 작동** (실행기법 76% 편중은 다운로드 동기와 일치) |
| 확신도(confidence) | 상 60 · 중 7 · **하 0** · unsorted 0건 | **게이트 죽음** — 18일간 '하'가 한 번도 안 나왔다 |
| 자산 태그(assets) | 33가지 조합인데 상당수가 **순서만 다른 같은 조합** (`[강의, 채널]` vs `[채널, 강의]`) | **필터 파편화** |
| 노트끼리 연결 | `[[링크]]` **0개** | 그래프에서 전부 고립. 하나를 열어도 옆 노트로 못 감 |
| 인덱스 | MOC·목록 노트 **없음** | 67개 파일이 평면으로 쌓임 |
| **실행 추적** | `status` 67건 전부 active · 실행 로그 전부 `(아직 없음)` | **제안 67건 중 실행도 기각도 기록된 게 0건** |

### 이게 뜻하는 것

지금 구조는 **"그날 데일리에서 한 번 보고 지나가는" 흐름**이다. 3주 전 노트를 다시 만날 경로가 사실상 없다. 검색은 되지만, 검색은 "찾을 게 있다는 걸 이미 알 때"만 작동한다.

민수 특성상 "쌓아두고 나중에 꺼내 보기"는 작동하지 않는다. **밀어주는 구조가 있어야 자산이 된다.** 지금은 자산이 아니라 로그다.

## 개선 의견 (우선순위)

1. **주간 회수 한 장** — 매주 지난 7일 노트의 "지금 제안"만 모아 3개로 추려 데일리에 올린다. 하나만 한다면 이것. 67개를 다시 읽을 필요 없이 3개만 보면 된다.
2. **기각도 한 동작으로** — 안 할 제안은 `status: dropped`로 닫는다. 지금은 67건이 전부 미해결로 남아 심리적 부채만 쌓인다.
3. **확신도·카테고리 게이트 재조정** — 전부 "상/세계관"이면 필드가 없는 것과 같다. 카테고리 후보를 좁히고 "하" 판정 기준을 강화해야 unsorted가 살아난다.
4. **노트 생성 시 [[링크]] 최소 1개 강제** — 관련 기존 노트나 프로젝트 MOC로. 그래프에서 우연한 재발견이 생기는 지점이 여기다.

1·2번이 "다시 꺼내 쓴다"의 핵심이고, 3·4번은 그 다음이다.
