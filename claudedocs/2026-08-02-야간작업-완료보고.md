# 1부. 무엇이 바뀌었나

## 이제 이렇게 동작합니다

```
PLAUD로 보내기
  ├─ 5시간 이하 & 480MB 이하 → 지금까지와 동일 (재인코딩 없음)
  ├─ 5시간 이하 & 용량 초과   → 모노 64kbps 압축 후 업로드
  └─ 5시간 초과              → 자동으로 N개 파트로 분할
                              → 파트별 순차 업로드
                              → 파트별 전사를 하나로 병합
                              → 병합본으로 인사이트 노트 1개 생성
```

## 음질에 대한 정직한 답

- **분할은 손실이 0입니다.** 스트림 복사(`-c copy`)라 재인코딩을 하지 않습니다.
- **압축만 손실이 있습니다.** 다만 이건 5시간 안인데 480MB를 넘는 드문 경우에만 발동하고, PLAUD는 전사용이라 전사 품질에는 영향이 없습니다(STT 엔진은 어차피 모노로 다운믹스합니다).
- 실측: 15분 강의 음성 기준 원본 13.95MB → 모노 64kbps 7.14MB. 6시간이면 약 360MB → 약 180MB.

## 말이 잘리지 않게

균등 분할 지점 그대로 자르면 문장 한가운데서 끊겨 그 문장이 양쪽 파트 모두에서 깨집니다. 그래서 **균등 지점 ±90초 안에서 가장 긴 무음을 찾아 그 중앙에서** 자릅니다.

실제 강의 음성 검증: 목표 지점에서 2.5초 무음을 찾아 424초 지점에서 절단 → 파트1 끝 "…진행하면 될 것 같아"에서 파트2 시작 "진행하면 될 것 같아라고 요청을 한번 해보고요"로 자연스럽게 이어짐.

## 없앤 것

| 없앤 것 | 남긴 것 |
|---|---|
| MP3 다운로드 버튼 | PLAUD로 보내기 |
| 화질 선택 + 영상 다운로드 | 시작/끝 구간 입력 |
| 2~5분할 버튼 | 진행률 (분할 시 파트 표시) |
| 서버 `/download`, `/download-video`, `/download-split`, `/file` | 회의끝(`plaud-meeting`) 기능 그대로 |

분할 버튼의 ffmpeg 로직은 버리지 않고 `audio-split.js`로 옮겨 자동 분할에 재사용했습니다.

## "다시 꺼내 쓸 수 있나?" → **이게 안 되고 있었습니다**

| 문제 | 실측 |
|---|---|
| **제안이 닫히지 않음** | 제안 67건 중 실행/기각이 기록된 게 **0건**. status 67건 전부 active |
| **노트가 고립됨** | 노트 간 `[[링크]]` **0개** — 하나를 열어도 옆 노트로 갈 수 없음 |
| **확신도 게이트 죽음** | 확신도 '하' 0건, unsorted 0건 — 18일간 한 번도 안 걸러짐 |
| **태그 파편화** | `[강의, 채널]`과 `[채널, 강의]`가 별개로 세어져 33가지로 흩어짐 |

**즉 자산이 아니라 로그였습니다.** 그날 데일리에서 한 번 보고 지나가면 다시 만날 길이 없었습니다.

## 그래서 만든 것: 주간 회수

검색은 "찾을 게 있다는 걸 이미 알 때"만 작동합니다. 67개를 다시 열게 하는 대신 **매주 3개를 데일리로 밀어 넣습니다.**

**오늘 새벽 실제로 1회 돌렸고, 결과가 이미 데일리에 들어가 있습니다:**

1. Claude Project 고정지침 패턴 → 김혜수 컨설팅 정리양식으로 변환 (8/3 착수 임박)
2. claude-watch + Remotion 스킬로 쇼츠 벤치마킹 테스트 (유튜브 파이프라인)
3. 스크롤 월드 스킬 설치만 — 계정 연결·생성 없이 (라운지 팩토리 3호 스프린트)

상황 팩을 읽고 이번 주 우선순위와 맞물리는 것만 골랐고, 자산도 컨설팅/채널/제품으로 분산했습니다. 넘긴 5건도 각각 이유를 남겼습니다.

**아무 동작도 요구하지 않습니다.** 14일 넘게 손 안 댄 노트는 자동으로 `stale`로 내려갑니다(삭제 아님, 회수 대상에서만 제외). 오늘 36건이 그렇게 정리돼 active가 67 → 31건이 됐습니다.

- 자동 실행: **매주 월요일 오전 8시** (launchd 등록 완료)
- 수동 실행: `~/Projects/youtube/server/plaud/insight-weekly-review.sh`
